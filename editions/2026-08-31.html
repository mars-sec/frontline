Bissa Scanner: When the Threat Actor's Ops Center Runs on Claude Code

The DFIR Report found an exposed operator server behind "Bissa scanner," a mass-exploitation platform weaponizing React2Shell (CVE-2025-55182) that scanned millions of internet-facing targets and confirmed over 900 successful compromises. Claude Code and OpenClaw were embedded directly in the threat actor's day-to-day workflow, troubleshooting and orchestrating the exploitation, hit-scoring, and secret-harvesting pipeline. Rather than dumping data indiscriminately, the operator triaged tens of thousands of stolen .env files and credentials across AI, cloud, payments, and database platforms, concentrating deeper collection on high-value victims in finance, crypto, and retail — and the sloppy server even exposed the operator's Telegram handle and alerting bots.

This is a rare, granular look at an adversary using the same AI coding agents you're studying, to build and iterate exploitation tooling at internet scale — essential context for anyone thinking about where implant engineering and capability development are headed next.

Turning a macOS CoreAudio Crash Into a Working Exploit

Google Project Zero's second installment on CVE-2024-54529 walks through the full exploitation of a type-confusion bug in macOS's coreaudiod daemon, including a custom TinyInst-based heap dumper, an IDAPython hunt for exploitation primitives, and a chain that defeats malloc_tiny zeroing by reclaiming freed property-list memory into an uninitialized-field object. It's a rare blow-by-blow of real heap exploitation complete with dead ends, not just the polished final trick.

This is exactly the caliber of primary-source exploit-dev writeup — dead ends, custom tooling, heap feng shui — that belongs in your implant/exploit-dev study queue.

Project Zero Cracks Open a Two-Decade-Old Windows API

James Forshaw traces GetProcessHandleFromHwnd from its Vista-era windows-hook implementation through its move into the Win32k kernel, finding Microsoft's own documentation about its security model is largely wrong. The deep dive shows how a missing access check let any process with UI Access or equal integrity open handles to protected or sandboxed processes — the bug behind a public Quick Assist UAC bypass, fixed as CVE-2023-41772 — and how the fix still leaves gaps for higher-integrity callers.

Straight into your Windows internals lane — a masterclass in reading kernel source and API documentation skeptically to find privilege-boundary bugs.

C:\node_modules Is Still an Open Door on Every Windows Node App

ZDI details a long-known but unpatched Node.js design quirk: on Windows, module resolution walks all the way up to C:\node_modules, a directory any low-privileged user can create and seed with malicious modules. The post demonstrates real local privilege escalation in npm CLI (now patched) and Discord's desktop app (unpatched, CVE-2026-0776), triggered whenever an optional dependency is missing — and Node.js, npm, and Discord all decline to treat it as a vulnerability.

A textbook local-privesc primitive hiding in a security-policy loophole — solid tradecraft reference for red-teaming Electron/Node targets.

Vulnerability Research: Crypto & Side Channels

Cloudflare Re-Ran Spectre Against Its Own Production Workers — And It Still Leaked

Cloudflare's security team revisited remote Spectre attacks on Workers, building a new proof-of-concept that reliably leaked 12 bits per second at 99% accuracy from live production infrastructure, exploiting a gap in their 2021-era Dynamic Process Isolation defense. The published paper details the full chain: a speculative type-confusion gadget for arbitrary 64-bit reads, PLRU cache-based signal amplification, and a noisy remote WebSocket timer, all built around JavaScript running in tens of thousands of co-located tenants on the same process. The attack was already mitigated before publication with no signs of prior exploitation.

A rigorous, code-level treatment of stabilizing microarchitectural side channels in a real multi-tenant cloud runtime — exactly the over-your-head-today material that pulls RE skills forward.

Cracking RSA Keys That Are Missing Half Their Randomness

Trail of Bits and the badkeys project found hundreds of real-world RSA and DSA keys with structured blocks of zero bits — "short-sleeve" keys — that can be factored with a novel polynomial-based technique instead of brute-force integer factoring. They traced one pattern to a type-mismatch bug in old CompleteFTP code, recovering 603 RSA and 74 DSA private keys from internet scans, and connect the technique to General Number Field Sieve foundations.

A clean lesson in turning a subtle key-generation bias into a practical break, with reverse-engineered root cause — good material for building crypto and protocol tooling intuition.

Ransomware & Intrusion Tradecraft

SEO-Poisoned 'ManageEngine' Installer Leads Straight to Akira Ransomware

The DFIR Report traces a Bing SEO-poisoning campaign that lured IT admins to a fake ManageEngine OpManager download, sideloading a Bumblebee loader via a trojanized MSI that then dropped an AdaptixC2 beacon. Within 44 hours the actor had dumped NTDS.dit, exfiltrated 75GB via FileZilla/SFTP, and deployed Akira ransomware, with infrastructure overlap tying the campaign to a parallel Ivanti-VPN credential-stealer operation.

A full DLL-sideloading and beacon-chain writeup laid out end to end — useful ground truth for implant and loader design as well as detection-evasion tradecraft.

A Blockchain-Backed C2 and an AI-Built Malware Framework Walk Into a Domain

The DFIR Report's flash alert covers EtherRAT, which resolves its C2 configuration via Ethereum smart contracts (EtherHiding), handing off to TukTuk — a malware framework reportedly AI-generated — that can fall back on Arweave blockchain dead-drops and a grab-bag of SaaS platforms like ClickHouse, Supabase, Dropbox, and GitHub Issues for resilient command and control. The intrusion ends in domain-wide deployment of The Gentlemen ransomware via a malicious Group Policy Object.

Decentralized, SaaS-abusing C2 architecture is where evasion tradecraft is heading — solid blueprint material for your own C2 and EDR-evasion experiments.
