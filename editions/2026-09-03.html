Windows Internals & Offensive Tradecraft

Windows 8.1's Hidden Address Space Explosion Enabled Control Flow Guard—and Completely Changed the Memory Layout

Alex Ionescu documents how Windows 8.1 removed the 44-bit VA limitation that constrained Windows 7/8 to 16 TB, expanding to 256 TB—a change marketed as trivial but driven entirely by CFG's requirement for a 2 TB bitmap on 64-bit systems. The shift also changed how reserved memory charges commit; 1 TB reservations that cost 16 GB commit on Windows 7 now cost 128 GB on 8.1, breaking large-scale memory tests. The resulting address space layout became far easier to decode by nibble inspection (0xFFFFD* = kernel stack, 0xFFFFC* = paged pool, etc.).

If you're doing implant development on modern Windows, you need to understand the actual address space layout that CFG forced. The new ranges matter for reliable code location, ASLR entropy analysis, and understanding why certain old exploitation techniques broke.

modexp details injecting shellcode into new processes by embedding payloads in RTL_USER_PROCESS_PARAMETERS: command line, environment block, or C runtime data. This trades off against traditional VirtualAllocEx+WriteProcessMemory patterns and keeps the payload in legitimate process memory structures. Useful when those APIs are heavily monitored.

Total Recall: Weaponizing Windows 11's Recall Feature for LPE via WNF State Triggers

MDSec discovered a Windows 11 elevation of privilege in the Recall-related PolicyConfiguration scheduled task. The task runs as SYSTEM and has WNF state change triggers that can be modified by low-privilege users. Attackers can write to WNF state names to trigger the task, which then executes a COM handler (ShellConfigTask.dll). By replacing the registry key with a symbolic link before task execution, arbitrary registry writes in SYSTEM context are achievable, enabling service image path hijacking.

Windows 11 scheduled task abuse + WNF primitive = arbitrary registry writes as SYSTEM. The symbolic link race condition is tight but reliable in a lab setting. Shows how feature-flagged OS components (Recall) can introduce unexpected privileged code paths.
