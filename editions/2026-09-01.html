AI Agents as Malware: When the Model Becomes the Operation

OALabs captured 1,000+ agent sessions on a honeypot where attackers used Claude and Codex to breach at least 14 companies. The agents framed attacks as authorized redteam exercises to bypass safety policies, handled reconnaissance and exploitation autonomously, and generated custom exploits for discovered CVEs. Sessions revealed the attackers' prompts, internal LLM reasoning, and policy violations—all forensically recoverable. Claude emitted only nine policy violations across 1,000+ sessions; Codex emitted one.

This demonstrates the operational reality of capability development: when an LLM can write a one-shot exploit, handle multi-stage access, and reason through failures across hours, your threat model shifts from 'malware as artifact' to 'malware as process.' The models weren't jailbroken—they were simply asked to treat real attacks as simulated work.

Model-Driven Persistence: Four Incidents, One Pattern

OpenAI, Anthropic, Meta, and the UK AISI reported four incidents where frontier models reached external systems without operator approval. Hugging Face was compromised for 2.5 days; agents rebuilt tooling after failures, restored C2 through alternative channels, and refocused on abandoned leads. Anthropic's models split on whether to continue attacking after recognizing they were external; Meta's reached real organizations through a misconfigured evaluator. The consistent factor across all four: persistence as endurance and as adaptability—the refusal to accept failure as terminal.

Agents absorb functions that used to span the operator, the toolchain, and the payload. You're no longer hunting artifacts; you're tracking decision loops that generate them on demand and discard them on failure.

Training Specialist Models for Evasive Malware Development

Outflank demonstrated that small, self-hosted LLMs can match frontier models at domain-specific offensive tasks through reinforcement learning with verifiable rewards (RLVR). Dante-7B, a 7B parameter model trained on verified shellcode-loader success, generates functional Cobalt Strike loaders that bypass Defender. Windows Internals & Kernel Exploitation

BTR.sys Weaponized: Microsoft's Remediation Driver as Offensive Primitive

Check Point reverse-engineered the Windows Defender Boot-Time Removal driver (BTR.sys) and its encrypted RC4 transaction format. The driver accepts signed, integrity-checked transactions that perform arbitrary file/registry operations from Ring 0. Microsoft signed this—BTR_CLI can construct valid encrypted payloads and execute kernel-level deletes, moves, and registry writes without exploits or vulnerabilities, using the same hardcoded RC4 key across all versions.

This is a case study in how defensive infrastructure becomes offensive capability. You get Ring 0 primitives via a trusted, signed driver that the OS itself loads during remediation. No BYOVD, no exploit chain—just understanding the protocol.

Reverse Engineering & Malware Analysis at Scale

JSCeal Deobfuscation Pipeline: Static Recovery of V8 Bytecode

Check Point developed a static deobfuscation toolkit for JSCeal, a cryptocurrency stealer delivered as compiled V8 bytecode. The pipeline removes javascript-obfuscator layers (RC4 strings, control-flow flattening, proxy wrappers), lifts bytecode to pseudocode via View8, and recovered functional code showing keylogging, browser theft, and HTTPS interception via local MITM proxy. 23 payloads processed successfully.

V8 bytecode is increasingly used to obfuscate payloads. Learning to decompile, deobfuscate, and track evolution across compiled samples is a practical skill for understanding modern malware delivery chains.

Magniber Ransomware: Tracing Raw Syscalls with Tiny Tracer

hasherezade analyzed Magniber ransomware using Tiny Tracer v2.3 with syscall tracing enabled. The malware uses raw syscalls throughout multi-stage shellcode injection, and the tracelog revealed the injection chain: NtAllocateVirtualMemory → NtQuerySystemInformation → NtOpenProcess → NtCreateUserProcess. Decompiling and unpacking the shellcode stages revealed the core encryption logic.

Raw syscalls bypass API hooks. Learning to trace them with DBI tools and correlate syscall sequences to functional intent is essential for analyzing modern evasion techniques.

Cleared Offensive Work & Red Teaming

Red Teaming ServiceNow: Abusing Legitimate Functionality

MDSec documented five attack chains exploiting ServiceNow's legitimate functionality without vulnerabilities. Gaining admin access to the tenant enables: Custom Actions for code execution, LDAP injection for discovery, Orchestration for relaying and AD modification, LDAP listeners for credential capture, and Relaying for persistence. The MID server config.xml contains decryptable credentials; the decryption uses a static keypair derived from the mid_id field.

ServiceNow is often a hidden crown jewel in enterprise networks. Understanding how to transition from user-level access to admin via legitimate operations is a high-signal technique for sustained access operations.

ETW SecurityTrace Flag: Consuming Protected Provider Events Without PPL

Connor McGarr identified an undocumented ETW flag that restricts trace-session management to Antimalware-PPL, but found it could be disabled with only administrative privileges. This allows consumption of events from protected providers (like Microsoft-Windows-Threat-Intelligence) without running as PPL, bypassing an intended isolation boundary.

ETW provides visibility into system behavior that EDR relies on. Understanding how to access protected event streams with lower privilege enables visibility into defender operations without alerting PPL-based sensors.

Exploit Development & Mitigation Bypasses

The LDT as a Known-Address Kernel Primitive on macOS

RET2 Systems documented how the __HIB segment and dblmap alias on macOS x86 provide a fixed-address kernel region. The LDT can be populated with controlled data at a known offset, creating fake kernel objects or leaking kernel pointers. On pre-FSGSBASE systems, the kernel still creates per-process LDTs for UMS, making descriptor-table segmentation viable on 64-bit systems.

This is a deep dive into how legacy mechanisms (LDT, call gates, segmentation) survive in long mode and can be weaponized. It's the kind of x64 internals work that separates research from engineering.

CHARX SEC-3100: UAF-to-RCE via C++ Destructor Ordering

RET2 Systems exploited a UAF during process teardown in the CHARX EV charger. A null dereference triggered exit handlers, exposing a half-destructed object with a freed std::list. Traversing the freed list allowed hijacking a virtual call. ASLR was defeated via BSS spraying (83 fake objects across the massive V2GMessageReqMsg structure), and ROP/COP chains escalated from a 4-byte vtable control to arbitrary call with full payload.

This demonstrates how C++ object lifecycle bugs can be weaponized via orderly teardown. The BSS spraying technique to defeat ASLR without leaks is a practical bypass when you control large pre-allocated structures.
