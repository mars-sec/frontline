Windows Internals & Kernel Techniques

Randomizing Kernel Addresses Without Global Variables: KASLR via Dynamic Relocation

Windows 10 Anniversary Update introduced dynamic relocation tables in the PE format, allowing the compiler and linker to emit relocations for absolute addresses that point outside the image (like kernel PTE_BASE). The bootloader processes these relocations post-ASLR randomization. This elegantly solves the performance problem of random kernel address space layout while maintaining security.

This is how Microsoft closed the PTE_BASE attack vector using compiler-owned infrastructure—the interplay between PE format, linker, compiler, and OS loader that modern exploits must contend with.

Call Gates Still Work on x64: Descriptor Table Segmentation in Long Mode

Even in 64-bit long mode, x64 processors still support LDT and call gates. Windows uses this for User Mode Scheduling, remapping TEB below 4GB to work around the 32-bit descriptor base limit. The technique was exploitable until Anniversary Update blocked LDT creation for non-UMS code paths.

A reminder that 'legacy' CPU features often have living security implications; understanding what hardware actually supports vs. what documentation implies can reveal bypass opportunities.

Windows 10 19H1: Kernel-Mode ETW Callbacks and Dynamic Syscall Hooks

Dynamic tracing support in 19H1 introduced KeSetSystemServiceCallback for system call hooks, EtwRegisterEventCallback for kernel-mode ETW consumption, and KeSetTracepoint for dynamic kprobes. All require valid trace callbacks and are protected by PatchGuard, but expose a new instrumentation surface.

Official kernel instrumentation hooks—understanding the registration and callback mechanism is essential for both defensive detection and offensive introspection of live systems.

Process Hollowing Breaks on Windows 11 24H2: Adapting RunPE for Modern Windows

Windows 11 24H2's hotpatching support triggers RtlpInsertOrRemoveScpCfgFunctionTable, which fails on MEM_PRIVATE implants. Alternative techniques (Transacted Hollowing, Process Ghosting, Process Overwriting) map payloads as MEM_IMAGE, or NTDLL can be patched to bypass the check.

RunPE is foundational implant loading; understanding how OS changes force technique evolution and what alternative approaches work is essential for loader development.

PCPJack: Cloud Worm Stealing Credentials and Evicting TeamPCP

PCPJack is a Python-based credential-harvesting worm that spreads across Docker, Kubernetes, and exposed cloud services while removing TeamPCP artifacts. It harvests credentials from .env files, SSH keys, cloud metadata, and wallet software, exfiltrates via Telegram, and propagates using Common Crawl parquet files.

Real-world cloud-focused malware doesn't mine crypto; it steals credentials for fraud and extortion. Understanding cloud-native attack surface (IMDS, service accounts, bind-mounted filesystems) and lateral movement patterns is critical for both offense and defense.

Administrator Protection replaces UAC with a shadow admin account, but 9 separate bypasses exist. New UAC-replacement mechanisms inevitably have logical flaws; understanding how logon sessions, drive letters, and symbolic links interact at the kernel level reveals elevation paths others miss.
